# 外壳与对话框

外壳是所有页面共用的框架。它分层放置背景、页面、横幅、浮层与提示，不放导航栏。页面之间的跳转由菜单入口负责。

## 分层

自下而上：

| 层 | 内容 | 部件或插槽 |
| --- | --- | --- |
| 背景 | 赛季背景 | `core:shell.backdrop` |
| 横幅 | 连接横幅 | `core:shell.banner` |
| 主区 | 当前路由的页面 | `core:screen.*` |
| 浮层 | 对话框层、确认框 | 插槽 `core:shell.overlay` |
| 提示 | 提示栈、工具提示 | `core:shell.toast`、`core:shell.tooltip` |

对局页的横幅移到顶栏下方。浮层与提示层在所有页面都在。

外壳根节点高度为 `100dvh`，`overflow` 为 `hidden`：整页不滚动，需要滚动的内容在面板或对话框框体内滚。对局页（`bare`）主区无内边距，战场铺满。

## 对话框

对话框不是路由。打开对话框不改地址。

对话框是界面状态，不经意图总线。

| 对话框 id | 内容 | 菜单顺序 | 出现条件 |
| --- | --- | --- | --- |
| `core:dialog.profile` | 个人配置，也是对局内设置 | 20 | 总是 |
| `core:dialog.loadout` | 干员调配 | 30 | 后端有 `loadout` 能力 |
| `core:dialog.guide` | 玩法说明 | 40 | 总是 |

- 对话框注册表以 id 为键。每项有标题文案键、可选的菜单元数据与可选的加载函数。
- 注册项可选 `size` 定对话框框体，默认 `panel`：`panel` 居中窄栏（宽不超过 40rem，个人配置）；`wide` 大卡片（宽不超过 72rem，`core:dialog.guide`）；`full` 铺满屏幕（`core:dialog.loadout`）。内容超出时在框体内滚动。
- 对话框的内容是同 id 的部件，所以模组可以对它 `replace` 或 `wrap`。
- 模组可以用自己的 id 加对话框。同一 id 注册两次会报错。
- `openDialog(id)` 先加载对话框的模块，再显示它。
- `closeDialog()` 关闭当前对话框。Esc、浏览器与 Android 的返回键、鼠标返回键都调用它。
- 对局内的设置就是 `core:dialog.profile`。
- 简报的干员调配按钮打开 `core:dialog.loadout`。房间的干员调配按钮展开房间下方的干员调配面板。

## 确认框

`requestConfirm(options)` 在外壳浮层上排队一个确认框，按玩家的回答兑现为 `true` 或 `false`。

- `cancel` 为 `null` 时是只有一个按钮的告知框。
- `tone: "danger"` 标出危险操作。
- 移出玩家、离开简报等操作先经确认框。

## 菜单入口

菜单入口 `core:menu.entry` 是普通部件，不固定在外壳的某一层。各页的布局部件把它放进自己的区域：

- 入口页：角落区
- 房间页：头部
- 对局页：不放，离开由退出键负责

菜单项有两种来源：

- 路由项：路由定义上的 `menu` 元数据。
- 对话框项：对话框注册表上的 `menu` 元数据。

两者的元数据形状相同：文案键 `label`、顺序 `order`、出现条件 `when`。`when` 与插槽插入的条件是同一套，见 [部件与插槽](./05-part.md#出现条件)。菜单部件不写死任何一项。

| 菜单项 | 来源 | 顺序 | 出现条件 |
| --- | --- | --- | --- |
| 入口页 `/` | 路由 | 10 | 不在房间里（`room: false`） |
| 个人配置 | 对话框 | 20 | 总是 |
| 干员调配 | 对话框 | 30 | `capability: "loadout"` |
| 玩法说明 | 对话框 | 40 | 总是 |

离开房间不在菜单里，见 [页面与路由](./03-route.md#离开房间)。

## 错误边界

每个部件渲染在错误边界里，以部件 id 为键。

| 边界 | 用在 | 出错时显示 |
| --- | --- | --- |
| 页面边界 | 页面部件、对话框内容 | 错误面板：重试、返回大厅 |
| 部件边界 | 页面内的其他部件 | 错误面板：重试 |

- 部件出错只替换这个部件，周围的部件照常工作。
- 对局页的战场 `core:match.field` 有自己的部件边界，渲染出错只替换战场。
- 「返回大厅」走离开房间的流程。
- 错误面板本身是部件 `core:shell.error`，未定义时用内置面板。

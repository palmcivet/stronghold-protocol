# 部件与插槽

界面由部件组成。部件是按 id 注册的 React 组件，通过 `<Part id>` 渲染。插槽是布局中的容器部件，其他部件可以插入其中。

部件 id 的格式是 `<命名空间>:<名称>`。宿主的部件都在 `core:` 命名空间下，如 `core:room.seat`。

## 示例

房间页的主区是插槽 `core:room.main`。它的默认子部件是席位列表与独立模拟说明：

```text
core:room.main
  core:room.roster   order 10
  core:room.brief    order 20   when { coop: false }
```

在联合模拟的房间里，`core:room.brief` 的条件不满足，不显示。另一个部件插入 `core:room.main` 时，按 `order` 排进这两项之间或前后。

## 注册

| 操作 | 作用 |
| --- | --- |
| `definePart(id, component, options)` | 在 id 下注册部件；同一 id 注册两次会报错 |
| `replacePart(id, component)` | 替换部件；同一 id 的第二个替换会报错 |
| `wrapPart(id, wrapper)` | 包装部件；包装组件收到被包装的组件 `Inner` 与原有 props |
| `insertPart(insert)` | 把部件插入容器 |

- 每个操作都返回撤销函数。
- 只有注册时带 `extensible: true` 的部件允许 `replace` 与 `wrap`。不开放的部件仍可被插入容器。
- 多个包装按注册顺序串联，先注册的在最外层。
- `title` 选项给出部件的标题文案键，分页容器用它作为分页名。

## 插入

插入项的字段：

| 字段 | 含义 |
| --- | --- |
| `into` | 目标容器 id |
| `id` | 插入的部件 id |
| `order` | 排序值，小的在前 |
| `when` | 可选的出现条件 |
| `component` | 可选；id 尚未注册时，以它注册部件 |

- 容器的默认子部件与插入项是同一种形状。
- 同一容器的子部件按 `order` 排序。
- `order` 相同时，默认子部件在前，插入项按插入顺序。
- 容器可以为空，空容器也能接受插入。

## 出现条件

`when` 是声明式的谓词，只读会话、房间与对局的公开状态，不接受任意函数。所有给出的键都满足时才显示。

| 键 | 满足条件 |
| --- | --- |
| `capability` | 后端有这项能力 |
| `seat` | 玩家在房间中的身份：`host`、`player` 或 `spectator` |
| `coop` | 为真时房间是联合模拟，为假时是独立模拟 |
| `phase` | 对局公开视图的阶段等于此值 |
| `room` | 为真时服务端把玩家留在房间或对局里，为假时不在任何房间 |

菜单项的 `when` 也是这一套，见 [外壳与对话框](./04-shell.md#菜单入口)。

## 错误隔离

`<Part>` 的 `boundary` 决定错误边界：

| 值 | 边界 |
| --- | --- |
| `part`（默认） | 部件边界：出错时只替换这个部件 |
| `page` | 页面边界：出错时显示页面错误面板 |
| `none` | 不包边界，由调用方负责 |

边界与错误面板见 [外壳与对话框](./04-shell.md#错误边界)。

## 部件的约束

- 部件只读状态仓库，只经意图总线发出动作。替换后的部件做不到玩家本身做不到的事。
- 容器负责布局，不读游戏数据。
- 阶段切换只换布局部件。HUD 部件按阶段自行显隐。
- 纯展示的小件（阶标、价格、盟约圆片）是 `@alliance/ui` 的组件，不注册部件 id。
- 整备区、选中棋子菜单、朝向轮盘与棋子标签属于战场一侧，见 [战场](./14-field.md)。
- 一个部件对应一块玩家能叫出名字的界面；列表的容器与单项各是一个部件。
- 多处出现的同一信息只有一个部件（如 `core:match.info`），容器各自决定外框。

各页的部件与插槽见 [部件清单](./06-inventory.md)。

## 插入示例

模组可以把聊天面板插进房间侧区与对局侧区：

```text
insert into core:room.side      →  example/chat:panel
insert into core:match.hud.side →  example/chat:panel
```

消息走扩展信道，快捷键经意图总线注册。兼容模式没有扩展信道时，`when` 不满足，面板不出现。

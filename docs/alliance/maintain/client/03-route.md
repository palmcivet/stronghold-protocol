# 页面与路由

客户端有两层状态：

- URL 路由表示玩家在看哪一页，可以分享，刷新不丢。
- 在场状态表示服务端认为玩家在哪。

路由守卫在进入页面前对照在场状态，不一致时重定向。

## 路由

| 路由 | 页面部件 | 内容 |
| --- | --- | --- |
| `/` | `core:screen.entry` | 代号、创建或加入房间 |
| `/room/:id` | `core:screen.room` | 房间：席位、规则与准备 |
| `/room/:id/match` | `core:screen.match` | 对局：简报、选策略、对局、结算 |

- 每个页面就是注册在页面部件 id 下的部件，见 [部件与插槽](./05-part.md)。
- 个人配置、干员调配与玩法说明是对话框，不是路由，见 [外壳与对话框](./04-shell.md)。
- 对局页按阶段切换布局：`INFO_CHECK` 及以前是简报，`BAND_DRAFT` 是选策略，`RESULT` 或对局结束是结算，其余是对局 HUD。


## 页面区域

每页一个布局部件，区域即插槽或具名分区。

| 页面 | 区域 |
| --- | --- |
| 入口 | 标题区、表单区（代号、模式、难度、加入码）、角落区（菜单、语言、设置、玩法说明、恢复本机对局、服务器信息） |
| 房间 | 头部（房间码、邀请、模式难度、菜单）、主区（席位）、侧区（观众）、操作栏（房主控制、状态、准备 / 开始 / 干员调配 / 离开）、下方区（干员调配面板） |
| 简报与选策略 | 步骤头（离开、延迟、难度、步骤标题、倒计时）与主区三栏 |
| 对局 HUD | 战场铺满；HUD 分上、左、右、下、中央浮层五区。详情卡放在哪一区由布局部件决定 |
| 结算 | 标题区、玩家卡列、操作、扩展区 |

窄屏（手机横屏）由各页的布局部件按断点切换区域排布，部件本身不分端。


## 在场状态

在场状态是一个普通的 reducer，存在 `infra/store/presence.ts`，不使用状态机库。

| 状态 | 含义 |
| --- | --- |
| `disconnected` | 未连接 |
| `connected` | 已连接，不在任何房间 |
| `in-room` | 在房间里，带房间码 |
| `in-match` | 在对局中，带房间码 |

转移规则：

| 事件 | 结果 |
| --- | --- |
| 连接变为 `online` | 从 `disconnected` 进入 `connected` |
| 连接离开 `online` | 进入 `disconnected` |
| `welcome` | `connected`；恢复的会话随后由 `room.state` 报告房间 |
| `room.state` 且 `inMatch` 为真 | `in-match` |
| `room.state` 且 `inMatch` 为假 | `in-room`；屏幕上的结算保留，直到玩家离开它 |
| `room.closed` | `connected` |
| `m.public` 的阶段不是 `LOBBY` | 已在房间时进入 `in-match` |
| 玩家关闭结算 | 从 `in-match` 回到 `in-room` |
| 服务端接受 `room.leave` | `connected` |

master 后端不再给离开者发房间消息，所以离开由意图结果驱动，而不是等待房间消息。

## 守卫

守卫等待在场状态确定：先等连接上线（最多 8 秒），再给恢复的会话 1.5 秒报告房间。玩家还没输入代号时，在场状态视为未知。

| 路由 | 规则 |
| --- | --- |
| `/` | 服务端把玩家留在房间或对局里时，重定向到那一页 |
| `/room/:id` | 在场状态未知时回到 `/`；在别的房间时去那个房间；本房间已开局时去对局页 |
| `/room/:id/match` | 服务端没有宣布本房间开局时回到房间页 |

- 打开分享链接不会自动入座。不在任何房间时，房间页先请玩家确认加入、观战或返回。
- 服务端已确认玩家在该房间时，跳过确认。
- 在对局页刷新时，先经房间页重连，服务端确认对局仍在进行时才回到对局页。

## 跟随服务端

路由之外，外壳订阅在场状态，把页面带到服务端认定的位置：

- 创建或加入房间后进入房间页。
- 开局后进入对局页。
- 房间关闭或离开后回到 `/`。

## 离开房间

服务端仍把玩家留在房间里时，菜单入口不列入口页。离开只走房间操作栏的「离开房间」或对局页的退出键：

1. 确认后发 `room.leave`
2. 服务端接受后，在场状态回到 `connected`
3. 页面回到 `/`

直接打开 `/` 的，按在场状态重定向回房间或对局页。

## 按需加载

| 模块 | 加载时机 |
| --- | --- |
| 对局页的部件与战斗播放 | 进入 `/room/:id/match` 时 |
| 干员调配对话框 | 第一次打开时 |
| 玩法说明对话框 | 第一次打开时 |
| 其余页面与对话框 | 首包 |

模块加载后注册自己的部件，见 [部件与插槽](./05-part.md)。

# 按键

动作到按键的映射只有一张表，在 `infra/intent/keymap.ts`。部件只按动作 id 取键与显示，不写死键位。

## 动作

一项动作的字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 动作 id，`<命名空间>:<名称>` |
| `label` | 设置页显示的动作名文案键 |
| `keys` | 默认按键，`KeyboardEvent.code` 的值 |
| `intent` | 此刻要发的意图；动作不适用时返回 `null` |

`defineBinding(binding)` 往表里加动作，返回撤销函数。同一 id 定义两次会报错。模组用自己的命名空间定义新动作。

## 默认动作

| 动作 id | 默认按键 | 意图 |
| --- | --- | --- |
| `core:refresh` | `KeyR` | `g.refresh` |
| `core:levelUp` | `KeyD` | `g.levelUp` |
| `core:freeze` | `KeyF` | `g.freeze` |
| `core:ready` | `Space` | `g.ready`，切换准备状态 |

四项都只在备战阶段（`PREP`）且玩家有私有视图时生效。`core:ready` 还要求玩家此刻可以准备或已经准备。

## 玩家的修改

- 个人配置只存改过的键，在设置段 `core:keys` 的 `keymap` 里，以动作 id 为键。
- 改过的键覆盖该动作的默认按键。
- 一个键分给新动作后，原来的默认动作不再响应它。
- 每项动作最多存 4 个键。

## 触发

对局页的布局是对局 HUD 时，按键事件经映射表转成意图，交给意图总线。以下情况不触发：

- 按键是长按产生的重复事件
- 同时按着 Ctrl、Meta 或 Alt
- 焦点在输入框、文本框、下拉框或可编辑区域里

按钮上的按键提示读同一张表，随玩家的修改更新。

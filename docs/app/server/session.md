# 会话

连接升级之后，第一条业务帧是 `hello`。`ping` 可以在 `hello` 之前发送。每条连接每秒约 40 帧；超出时该帧回复 `RATE`，不进入业务。一秒内因限流丢掉的帧超过 400，连接以 `1008` 关闭。

`g.watch`、`room.loadout`、`room.spectate` 另计一个更小的额度：每秒 2 次，突发 6 次。这三帧的回复或随后推送体积大。超出时回复 `RATE`。

服务端约每 30 秒发一次 WebSocket ping。一个周期内没有 pong 的连接被断开。连接建立后 30 秒内没有 `hello`，以 `4002` 关闭。

## `hello`

客户端 → 服务端。

| 字段 | 约束 |
|---|---|
| `name` | 非空字符串，去首尾空白后至少 1 个字符，最长 12。控制字符与双向控制符会被去掉 |
| `token` | 可选。此前 `welcome` 发过的重连令牌，最长 64 |
| `version` | 可选。有则必须等于协议版本 `1` |

没有 `token`，或令牌对不上仍可恢复的会话时，服务端新建会话。`playerId` 形如 `p_` 加随机十六进制，只在本进程内唯一。令牌是 128 位十六进制，只发给拥有者。

同一令牌已绑在另一条连接上时，旧连接以 `4001` 关闭，客户端不应自动重连那条旧连接。会话登记已满且无法腾出空闲会话时，回复 `INTERNAL`。

## `welcome`

`hello` 的直接回复。随后如果该会话仍在房间里，服务端再推 [房间](./room.md) 与对局状态。

| 字段 | 含义 |
|---|---|
| `playerId` | 公开身份 |
| `token` | 重连令牌 |
| `name` | 规范化后的昵称 |
| `serverNow` | 服务端时钟，毫秒 |
| `version` | 协议版本 |
| `resumed` | 这次 `hello` 是否用令牌恢复了已有会话 |
| `rid` | 请求带了 `rid` 时原样返回 |

断线后的默认可恢复时间是 10 分钟。独立模拟的对局进行中断线时，该会话延长到数据包里的 `singleReconnectTime`（缺省 86400 秒）。合作对局的座位在窗口内继续用断开前的阵容。窗口结束，会话被清除，进行中的对局按离开处理。进程重启后内存中的房间和令牌都不再存在。

同一条活连接上再次 `hello` 是一次重同步：房间状态只回给请求者；对局全量状态至少间隔 1 秒才重发一次，间隔内的请求合并成一次。

## `ping` / `pong`

客户端 → `ping`，字段 `c` 为有限数字。服务端 → `pong`，字段 `c` 原样返回，`s` 为服务端当前毫秒时钟。带了 `rid` 时 `pong` 也带回。

## `ok`

业务帧被接受，且请求带了合法 `rid` 时的直接回复：`{ "t": "ok", "rid": <rid> }`。没有 `rid` 的已接受帧没有这条回复。状态变化由随后的推送表达。

不带 `rid` 的 `b.progress` 如果已经没有可接收它的对局，服务端不回复。带 `rid` 的失败仍回复 `error`。

## `error`

| 字段 | 含义 |
|---|---|
| `code` | 下表之一。无法识别的内部码对外写成 `INTERNAL` |
| `msg` | 给玩家看的短句 |
| `rid` | 请求带了合法 `rid` 时原样返回 |
| `detail` | 可选，给开发看的原因，最长 120 字符 |

| `code` | `msg` |
|---|---|
| `BAD_MSG` | 无效的请求 |
| `RATE` | 操作过于频繁 |
| `NOT_IN_ROOM` | 你不在房间中 |
| `ROOM_NOT_FOUND` | 未找到该同盟密钥对应的房间 |
| `ROOM_FULL` | 房间已满 |
| `ROOM_STARTED` | 模拟已开始 |
| `NOT_HOST` | 只有房主可以操作 |
| `NOT_READY` | 仍有玩家未就绪 |
| `WRONG_PHASE` | 当前阶段无法进行该操作 |
| `NO_FUNDS` | 资金不足 |
| `HAND_FULL` | 整备区已满 |
| `BOARD_FULL` | 已达到部署上限 |
| `BAD_TILE` | 无法部署在该位置 |
| `BAD_TARGET` | 无效的目标 |
| `SOLD_OUT` | 已售出 |
| `MAX_LEVEL` | 调度中心已达最高等级 |
| `NOT_YOUR_TURN` | 尚未轮到你 |
| `ALREADY` | 已完成该操作 |
| `TEMP_NOT_EMPTY` | 临时整备区不为空 |
| `ELIMINATED` | 你已被淘汰 |
| `SPECTATOR` | 观战中无法进行该操作 |
| `INTERNAL` | 服务器内部错误 |

## 关闭码

| 码 | 含义 |
|---|---|
| `4001` | 同一令牌在另一条连接上完成了 `hello`。旧连接不要自动重连 |
| `4002` | 超时未 `hello` |
| `1008` | 限流丢帧过多 |
| `1001` | 进程关闭。房间成员会先收到 `room.closed`，`reason` 为 `shutdown` |

# 术语表

- **资源键**：`<kind>:<path>` 形式的字符串，资源唯一的身份，见 [资源键](./02-key.md)
- **种类**：键的 `<kind>` 部分，决定文件规则，例如 `image`、`spine`
- **命名空间**：键路径的第一段，含义由使用方约定
- **文件条目**：清单里描述一个文件的对象：`role`、`name`、`format`、`bytes`、`hash`
- **需求清单**：`NeedsList`，一个包要哪些键
- **原始清单**：`RawCatalog`，提取工具取到的资源与来源
- **包清单**：`PackManifest`，运行时用来解析的清单
- **Spine 元数据**：`SpineMeta`，从 Spine 骨架里读出的事实，作为 `meta` 文件随模型发布
- **守卫**：`isXxx` 与 `xxxIssues` 一对检查函数，后者返回带路径的问题列表
- **层**：覆盖层里的一份包清单和它的地址，即 `AssetLayer`
- **覆盖层**：从低到高叠起来的一组层，高层的条目整条替换低层
- **回退链**：从一个键出发沿 `fallbackId` 依次取到的条目
- **refs**：包清单里领域 id 到键的映射，按 JSON 路径跨层合并
- **相对地址**：由键和文件条目算出的文件路径，见 [地址](./04-address.md)
- **文件根**：包清单的 `fileRoot`，相对地址从这里开始
- **版本参数**：绝对地址末尾的 `?v=<hash 前 12 位>`
- **空闲模型**：Spine 缓存里引用计数为零、还没卸载的模型
- **源码结构**：包的源码文件布局，见 [实现原理](./10-internals.md#源码结构)

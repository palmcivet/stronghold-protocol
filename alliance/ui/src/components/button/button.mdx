# Button

按钮触发一次操作。外观由 `variant` 决定，色调随变体取；`busy` 表示请求进行中。`ToggleButton` 保持开关状态。

```tsx [Code]
import { Button } from '@alliance/ui';

<Button variant="primary">主要</Button>
<Button variant="secondary">次要</Button>
<Button variant="ghost">幽灵</Button>
<Button variant="amber">琥珀</Button>
<Button variant="ice">冰蓝</Button>
<Button variant="danger">危险</Button>
```

:::

## 变体
| `variant` | 色调 | 说明 |
| --- | --- | --- |
| `primary` | `accent` | 主要动作，每屏一个 |
| `secondary` | `accent` | 默认值，次要动作 |
| `ghost` | `accent` | 无填充，只有边框 |
| `amber` | `amber` | 琥珀色，用于确认与开始 |
| `ice` | `ice` | 冰蓝色，用于信息类动作 |
| `danger` | `danger` | 危险动作，如离开与放弃 |

## 属性
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'amber' \| 'ice' \| 'danger'` | `'secondary'` | 外观与色调 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 控件高度，取 `size` 令牌 |
| `icon` | `IconName` | — | 标签前的图标 |
| `iconEnd` | `IconName` | — | 标签后的图标 |
| `square` | `boolean` | `false` | 宽高相等的图标按钮，需要 `aria-label` |
| `block` | `boolean` | `false` | 占满容器宽度 |
| `busy` | `boolean` | `false` | 忙碌：忽略按压；250 毫秒后底边扫光，不用转圈 |
| `onPress` | `(e: PressEvent) => void` | — | 按压回调，来自 React Aria |

## 行为与无障碍
- 按压时播放 `ui.click` 音效，宿主没有提供反馈时不播放（见 [反馈](/components/feedback)）。
- 填充变体右端有斜纹条；悬停与键盘焦点时四角角标合拢。
- `busy` 时按钮仍可聚焦，但不响应按压。
- 最小高度取 `size` 令牌，内容更高时撑开。

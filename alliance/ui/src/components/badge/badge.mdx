# Badge

短标签：状态、数量、阶级、筛选条件。`shape` 选择形状，`tone` 或 `color` 着色；阶级、难度等游戏概念由调用方换算成颜色，如 `color="var(--wsde-color-tier-3)"`。

```tsx [Code]
import { Badge, Hotkey, Text } from '@alliance/ui';

<Badge>待定</Badge>
<Badge tone="accent">就绪</Badge>
<Badge shape="pill" tone="gold" glow>
  盟约 <Text variant="number">6</Text>
</Badge>
<Badge shape="square" color="var(--wsde-color-tier-4)" label="四阶">
  4
</Badge>
<Hotkey code="KeyQ" />
```

:::

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 标签的内容 |
| `tone` | `ToneName` | `'neutral'` | 色调 |
| `color` | `string` | — | 任意 CSS 颜色，优先于 `tone` |
| `shape` | `'tag' \| 'pill' \| 'square'` | `'tag'` | 小方框、圆角胶囊、放一个数字的固定方块 |
| `icon` | `IconName` | — | 内容前的图标 |
| `glow` | `boolean` | `false` | 外发光 |
| `label` | `string` | — | 读屏读出的名称，设置后整个标签作为一张图读出 |
| `title` | `string` | — | 悬停时的浏览器提示 |

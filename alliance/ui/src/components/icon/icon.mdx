# Icon

内置图标由路径数据绘制，颜色取 `currentColor`，跟随所在文字的大小。装饰性图标对读屏隐藏；传 `label` 时作为图读出。

:::code-group

<div data-title="Preview">

<div className="wsde-doc-preview">

<IconDemo />

</div>

</div>

```tsx [Code]
import { Icon } from '@alliance/ui';

<Icon name="play" />
<Icon name="settings" label="设置" />
```

:::

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | `IconName` | — | 图标名 |
| `label` | `string` | — | 给出时作为图读出，否则对读屏隐藏 |
| `size` | `string` | — | CSS 长度；不给时为 `1em`，可由样式另行设置 |

可用的图标名如下，`ICON_NAMES` 导出同一列表：

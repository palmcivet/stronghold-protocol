# Card

一件事物的框，如模式、策略或玩家。`title` 显示在顶部，`tone` 给顶边画一条色带。

```tsx [Code]
import { Card } from '@alliance/ui';

<Card title="标准对局" tone="accent">四人协作</Card>
```

:::

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 卡片标题 |
| `selected` | `boolean` | `false` | 选中态 |
| `muted` | `boolean` | `false` | 弱化，用于暂不可用的事物 |
| `tone` | `ToneName` | — | 顶边色带的色调 |
| `layout` | `'column' \| 'row'` | `'column'` | 纵向堆叠，或排成一行：首项在行首，其余在行尾，如列表中的一行设置 |
| `as` | `'article' \| 'li' \| 'div'` | `'article'` | 渲染的元素 |

需要在一组选项里单选时，用 `Segmented` 的卡片形态或 `ListBox`。

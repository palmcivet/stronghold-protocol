# AvatarFrame

四角角标的头像框。缺少图片时，显示名字的第一个字，或 `icon` 指定的图标；`hue` 决定缺图时底色的色相。`startMark`、`endMark` 与 `tag` 在角上标出身份，`active`、`dimmed`、`empty` 标出状态。

```tsx [Code]
import { AvatarFrame } from '@alliance/ui';

<AvatarFrame name="阿米娅" src="/portraits/amiya.png" />
<AvatarFrame name="空席" empty />
```

:::

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | — | 名字，读屏读出；缺图时取首字 |
| `src` | `string \| null` | `null` | 图片地址；加载失败时回退为首字 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 大小 |
| `hue` | `number` | `162` | 缺图时底色的色相，单位为度 |
| `icon` | `IconName` | — | 缺图时显示的图标，代替首字 |
| `startMark` | `{ icon: IconName; tone?: ToneName }` | — | 起始侧上角的标记 |
| `endMark` | `{ icon: IconName; tone?: ToneName }` | — | 末端上角的标记 |
| `tag` | `string` | — | 末端下角的短文字 |
| `active` | `boolean` | `false` | 强调色的框，如当前行动者或已选中 |
| `dimmed` | `boolean` | `false` | 灰色 |
| `empty` | `boolean` | `false` | 空位，虚线底板与加号，不显示标记 |
| `label` | `string` | — | 覆盖读屏读出的名称 |
